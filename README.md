## Trim Enabler 是干什么的，两分钟确认你要不要

TRIM 是 SSD 的一条指令，作用是把已经删除的数据块提前告诉主控，让它有空回收，盘用久了不至于越写越慢。macOS 对苹果原装 SSD 默认开启 TRIM，你自己换成第三方 SSD 之后，系统不一定会替你打开。

Trim Enabler 干的就是这件事：给第三方 SSD 打开 TRIM，顺带能看 SSD 的 SMART 健康数据。

判断方法很简单，不用装任何东西。打开「关于本机」，点「系统报告」，在左侧找到 SATA 或 NVMExpress，看右侧「TRIM 支持」那一栏写的是「是」还是「否」。写「是」，说明系统已经管了，这个工具对你没有额外价值。写「否」，才是它发挥作用的时候。

Apple Silicon 的 Mac 存储焊在主板上，不存在自己换盘这回事，这类机器完全用不上。真正需要它的是还能拆硬盘的老款 Mac，尤其是换了第三方 SATA SSD 的那批。
